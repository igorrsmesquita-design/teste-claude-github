# teste-claude-github

Este é um projeto de teste para validar a integração entre o **Claude Code** e o **GitHub**.

## Objetivo

Servir como ambiente controlado para experimentar e validar fluxos de trabalho envolvendo o Claude Code interagindo com repositórios GitHub, incluindo ações como criação de arquivos, commits, branches e pull requests.

## Status

Projeto em fase de testes iniciais, sem funcionalidades de produção.
